# MathMate

初中数学教学辅助助手 —— 一个部署在教室的**课堂讲评决策系统**。

解决一个问题：让教师在讲评前 5 分钟，知道今天该讲哪几题、为什么讲、重点讲什么。

## 三条数据主线

```
教学资料 ──→ [知识图谱]   ─┐
                          ├──→ [讲评决策] ──→ 教师
作业照片 ──→ [题目结构化] ─┤
                          │
学生宠物 ──→ [选题 + 归因] ┘
```

1. **知识图谱**：教师上传课件/教案/试卷，自动抽取知识点并对齐到课标母版，经教师审核后形成校本图谱。
2. **每日作业解析**：教师拍照上传作业题面，自动切题、识别公式、标注知识点与难度，教师校对后发布。
3. **大屏宠物选题**：学生在教室大屏点击自己的学习宠物，选出想听老师讲的题目（≤3 题）并给出**归因**（完全没思路 / 卡住了 / 做错不知错在哪 / 想看更好方法 …）。
4. **讲评决策**：按归因加权 + 知识点重要度计算讲评优先级，给出讲评顺序、策略与关联素材。

## 数据资产（已就绪）

L1 知识图谱母版与配套教学数据已完成整理，位于 `data/` 与 `scripts/`，直接服务于知识图谱主线（FR-KG）与讲评优先级算法（§7 的 `exam_weight` 与前置出度 `normFanout` 均可直接由该数据计算）：

| 数据 | 规模 | 说明 |
| --- | --- | --- |
| `data/l1_seed.sql` | 253 节点 / 448 关系 | **PostgreSQL L1 母版种子**，对齐 DESIGN.md §3.2 schema；四类节点（知识点层级 178 / 思想方法 8 / 几何模型 16 / 易错点 51）、五类关系（PART_OF / PREREQUISITE_OF / RELATED_TO / COMMON_ERROR_IN / METHOD_FOR），确定性 UUID，幂等重导 |
| `data/junior_math_kg.json` | 178 节点 / 337 边 | 北师大 2024 新版教材知识点图谱（3 领域 / 34 章 / 141 知识点，155 条前置关系），带年级、学期、中考权重 |
| `data/teaching_layers.json` | 8 + 51 + 16 | 数学思想方法 / 高频易错点（错因+纠正，覆盖 49 个知识点）/ 中考几何模型 |
| `data/practice_recommend.json` | 778 题 → 69 知识点 | 知识点→易错点→对应练习推荐数据（源自 TAL-SCQ5K，已剔除高中题源） |
| `data/raw/tal-scq5k/` | 5000 题 | 原始数据集（好未来，研究用途） |

维护方式：编辑 `data/kg_source.json` → 依次运行 `python scripts/build_graph.py`、`python scripts/export_pg_seed.py`、`python scripts/align_practice.py`，全部数据与交叉引用自动校验重新生成。该知识点编码体系（`ch-XX` / `tp-XX-YY`，基于北师大新版教材章节）可作为设计文档待定决策 T7（L1 编码体系自建 vs 对接标准）的自建方案基线。

## 已可运行的应用

`apps/` 下是模块二 + 模块三的可运行切片：教师录入每日作业并关联知识点，学生在大屏点自己的宠物选出想听讲解的题目并给出归因，数据实时汇总到教师端。

```bash
cd apps/api && pip install -r requirements.txt && python -m app.seed && python -m uvicorn app.main:app --port 8000
```

教师控制台 http://localhost:8000/teacher/ ｜ 教室大屏 http://localhost:8000/screen/

VS Code / Cursor 里按 **F5** 一键启动调试，配置见 [.vscode/launch.json](.vscode/launch.json)。

- **作业录入**：拍作业照片直接识别（多模态模型读出题干、公式转 LaTeX、拆选项、估难度），或粘贴文本按题号切分；自动挂知识点候选后，教师逐题校对才能发布
- **大屏选题**：40 只萌宠（24 种动物）按真实座位排布，点宠物 → 座位号确认 → 选题（≤3）→ 选归因 → 提交，断网也能走完；被点中的宠物会从静态帧切成动图「活过来」
- **教师看板**：实时聚合按「人数 × 归因权重」排序，可下钻学生名单；宠物花名册显示能量与参与情况

要用照片识别需配置模型：`cp .env.example .env` 填入 `MATHMATE_LLM_API_KEY`，
再跑 `python scripts/llm_smoke.py` 验证。**不配也能完整运行**——自动退回
DESIGN NFR-AV-07 规定的降级路径（仅切题 + 手动录入），界面会如实标注「仅留存」而非假装识别成功。

知识点标注仍走**本地检索**（288 道已标注真题，留一法 top-3 命中 63.4%）。让 LLM 重排候选的路径也实现了，
但 288 题实测**测不出改进**（同一子集 50.4% vs 52.1%，置信区间重叠），故默认关闭 —— 详见 [apps/README.md](apps/README.md)。

演示数据为一个 40 人班级，作业的 12 道题取自 `data/practice_recommend.json`（真实初中数学题，非占位内容）。42 条回归测试覆盖了 PRD 中标注「不可妥协」的规则且不打网络，详见 [apps/README.md](apps/README.md)——其中也列明了尚未实现的部分（多点触控分区、鉴权、手机端通道、题目查重）。
