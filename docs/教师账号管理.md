教师与账号管理入口：/teacher/accounts.html（教师端顶部「账号管理」）。
学校管理员可维护本校教师的账号、姓名、角色、启用状态和任教班级，可新增账号与重置密码；教师可修改自己的密码。
密码最少 8 位。账号权限变更、停用、重置密码及个人改密会撤销原有登录凭据。管理员不能停用自己或撤销自己的管理员角色。
首个学校管理员由运维通过 app.models.Teacher 和 app.auth.hash_password 创建；不在公开接口提供注册或提权入口。部署时保留现有教师账号，单独创建 admin 管理员，随机初始密码保存在服务器 /opt/mathmate/admin-login.txt（权限 600）。
