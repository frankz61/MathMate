| `data/tal_scq5k_junior_mapped.jsonl` | 全量对齐结果(逐题带 topic_ids/原始标签/题源) |

| `scripts/build_graph.py` | 校验(重复id/悬空边/自环/前置环 + 教学层/练习推荐引用)→ 生成图谱 JSON 与 Neo4j 脚本 |
| `scripts/align_practice.py` | TAL 标签→图谱知识点规则映射(剔除高中题源)→ 生成练习推荐数据 |

**v2.0 换用北师大版(2022课标/2024新版)教材结构后的要点**:
- 七上(6章):丰富的图形世界 / 有理数及其运算 / 整式及其加减 / 基本平面图形 / 一元一次方程 / 数据的收集与整理(频数直方图在七上)
- 七下(6章):整式的乘除(整式乘除前移至七下)/ 相交线与平行线 / **概率初步(由九上移入)** / 三角形(含全等三角形,北师大全等在七下)/ 图形的轴对称 / 变量之间的关系(函数先行章节)
- 八上(7章):勾股定理(前移)/ 实数(含二次根式,三章合一)/ 位置与坐标 / 一次函数 / 二元一次方程组 / 数据的分析(新增箱线图)/ 命题与证明(北师大证明体系起点)
- 八下(6章):三角形的证明(等腰/HL/垂直平分线/角平分线的证明)/ 不等式与不等式组 / 图形的平移与旋转 / 因式分解 / 分式与分式方程 / **平行四边形(由九上移入,含多边形内角和)**
- 九上(6章,新版未出按现行版整理):特殊平行四边形 / 一元二次方程 / 概率的进一步认识 / 图形的相似 / 投影与视图 / 反比例函数
- 九下(3章,同上):直角三角形的边角关系 / **二次函数(北师大置于九下)** / 圆
- 与人教版主要差异:整式乘除、全等三角形、概率初步、勾股定理均更靠前;平行四边形下移八下、二次函数与圆后置九下;前置关系(PRE)按北师大教学顺序重新推导
- 七上/七下/八上/八下目录已对照电子课本网核实;九上/九下新版教材尚未出版,按现行北师大版目录整理,编号以正式出版教材为准

修改知识点或前置关系时:编辑 `data/kg_source.json` → 在项目根目录运行 `python scripts/build_graph.py` 重新生成,再运行 `python scripts/export_pg_seed.py` 更新 L1 种子。

## 五、构建初中数学知识图谱的建议路径

1. **定义 Schema(本体)**
   - 实体:学科→模块(数与代数/图形与几何/统计与概率/综合与实践)→章→节→知识点(细粒度到"勾股定理""配方法"级别)→题型/考点
   - 关系:`前置知识点(prerequisiteOf)`、`属于(partOf)`、`相关(similarTo)`、`考察(examinedBy→题目)`、`包含`
2. **知识点骨架**:用北师大版目录/课标2022 建层级树(第一部分资源)
3. **先修关系**:优先参考 **Junyi 练习表 prerequisite 字段** 和 **K12-KGraph 的边**;或用 wjn1996 的关系抽取方法从教材文本自动抽取
4. **存储与展示**:JSON/CSV → 导入 **Neo4j**(RCAE_graph_data 就是此路线);可视化可用 wanglin2/mind-map(支持JSON/XMind)做导图视图
5. **题目关联**:用 TAL-SCQ5K/CMM-Math 等题库 + 知识点自动标注模型,生成 `题目-考察→知识点` 边
6. **进阶应用**:基于图谱做学习路径推荐(先修+相似双结构,AAAI 2026 GraphRAG+RL 思路)、知识点追踪(pyKT 工具链)
