# 数据库部署与恢复

线上数据库为 PostgreSQL 16，Compose 文件在 `/opt/1panel/apps/postgresql/mathmate/docker-compose.yml`，数据目录为同级 `data/`。5432 只绑定 `127.0.0.1`。数据库 `mathmate` 的应用账号为 `mathmate`；密码与 PostgreSQL 管理密码均只保存在服务器 `.env` 文件，权限 600。不要把该文件提交到 Git 或发到客户端。

MathMate 的连接配置在 `/opt/mathmate/.env` 的 `MATHMATE_DB_URL`。迁移采用 SQLite Online Backup API 先备份，再按外键顺序复制数据到空的 PostgreSQL 库，逐表核对行数后切换。原 SQLite 文件与迁移前备份保留在 `/opt/mathmate/backups/`。上传图片仍位于 `apps/api/app/uploads`，需要同样做定期备份。

切换数据库不等于有备份策略。请将 PostgreSQL dump、SQLite 回退文件、图片上传目录纳入异机或对象存储的定期备份，并实际演练恢复。1Panel PostgreSQL 管理页与应用商店实例登记行为取决于安装方式；当前实例由 1Panel 管理的 Compose 创建。

本地开发默认 SQLite。PostgreSQL 驱动由 `psycopg[binary]` 提供。若本地也要连接 PG，配置 `MATHMATE_DB_URL=postgresql+psycopg://...`；不要将线上连接串或密码放进仓库。
